# Pattern Learning Schema

This schema documents the record structure stored in the JSON Lines format inside the patterns store (`.py2rust/patterns.jsonl`).

## Fields

| Key | Type | Description |
|---|---|---|
| `timestamp` | `string` | The ISO-8601 UTC timestamp when the pattern was recorded. |
| `pattern_id` | `string` | A unique snake_case identifier for the learned pattern (e.g., `int_to_float_div`). |
| `trigger_pattern` | `string` | The Python code construct or pattern that triggers the replacement (e.g., `/`). |
| `target_rust` | `string` | The incorrect or sub-optimal Rust code snippet that is generated by the compiler. |
| `replacement_rust` | `string` | The correct, optimized, or behavior-preserving Rust code suggestion. |
| `evidence_count` | `integer` | The number of failure examples analyzed to extract this pattern. |
| `confidence` | `float` | Generalization confidence rating between `0.0` and `1.0`. |

## Example Record

```json
{
  "timestamp": "2026-05-23T16:42:09.123456+00:00",
  "pattern_id": "int_to_float_div",
  "trigger_pattern": "/",
  "target_rust": "a / b",
  "replacement_rust": "a as f64 / b as f64",
  "evidence_count": 2,
  "confidence": 0.88
}
```
